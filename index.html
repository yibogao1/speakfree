        使用帮助 · 转发给同学前先看这个

        🍎 iPhone / iPad
        • 必须用 Safari 打开
        • 微信里收到链接 → 右上角 ··· → 在 Safari 中打开
        • 首次弹窗点「允许」麦克风
        • 语音评分可直接用
        🤖 安卓手机
        • 想自动评分：装 Edge 打开
        • 用 Chrome / 自带浏览器：录音对比照样练
        • 微信里收到链接 → 右上角 ··· → 用浏览器打开
        • 两种玩法都能记录成绩
        💻 电脑
        • 推荐 Edge，别用 Chrome
        • 不要双击 HTML 文件（那样没麦克风）
        • 地址栏点权限图标 → 允许麦克风
        • 语音评分可直接用

        关于

        • 完全免费：语音识别用浏览器自带的 Web Speech API，语音合成用系统内置 TTS，不调用任何付费服务。
        • 数据本地：练习记录保存在浏览器 localStorage，不上传服务器，可随时导出。
        • 安卓请用 Edge：Chrome 的语音识别走 Google 服务，国内连不上；Edge 走微软服务可用。
        • iPhone 请用 Safari：识别走 Apple 引擎，国内可用；微信和 Firefox 里不行。
        • 都不行时：用「录音对比」录下自己的声音和原声对照，任何浏览器都支持。
